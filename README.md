# Платформа проектных офисов

Многоуровневая платформа для управления проектными офисами, портфелями проектов и знаниями.

## 🚀 Возможности

### Многоуровневая структура
- **Проектные офисы** — независимые единицы управления со своими портфелями
- **Портфели проектов** — группировка по направлениям деятельности или архитектуры
- **Проекты** — с полной структурой WBS, задачами, документами, артефактами
- **Межофисные связи** — связь проектов разных офисов через задачи

### Управление проектами
- Структура проекта (WBS) с фазами, вехами, рабочими пакетами
- Задачи с приоритетами, статусами, исполнителями
- Документы с версионированием и категориями
- Артефакты проекта (дизайн, код, тесты, документация)
- База знаний проекта
- Связи между проектами

### Глобальная база знаний
- Единое хранилище знаний по всем проектам
- Категоризация и теги
- Уровни доступа (публичные, ограниченные, приватные)

### Система аутентификации и ролей

#### Роли пользователей:

**Администратор** (admin)
- Полный доступ ко всем функциям
- Управление офисами, портфелями, проектами
- Управление пользователями
- Межофисные связи

**Руководитель проектного офиса** (office_director)
- Управление своим офисом
- Создание и управление портфелями
- Управление проектами в офисе
- Просмотр глобальной базы знаний

**Руководитель проекта** (project_manager)
- Управление назначенными проектами
- Создание задач, документов, артефактов
- Межофисные связи через задачи
- Просмотр глобальной базы знаний

**Участник проекта** (team_member)
- Просмотр назначенных проектов
- Редактирование задач
- Просмотр документов и артефактов
- Создание записей в базе знаний проекта

**Наблюдатель** (viewer)
- Только просмотр всех разделов
- Без возможности редактирования

#### Демо-пользователи:

| Логин | Пароль | Роль | Описание |
|-------|--------|------|----------|
| admin | admin123 | Администратор | Полный доступ |
| director | director123 | Руководитель офиса | Управление ИТ-дирекцией |
| pm | pm123 | Руководитель проекта | Доступ к проектам 2, 5 |
| member | member123 | Участник проекта | Доступ к проектам 1, 2 |
| viewer | viewer123 | Наблюдатель | Только просмотр |

## 🛠️ Технологии

- **React 18** + TypeScript
- **Vite** — сборщик
- **Tailwind CSS** — стилизация
- **localStorage** — хранение данных

## 📦 Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предпросмотр продакшен-сборки
npm run preview
```

## 🔐 Система прав доступа

Каждая роль имеет набор разрешений:

- `view_dashboard` — просмотр дашборда
- `view_offices`, `create_offices`, `edit_offices`, `delete_offices` — управление офисами
- `view_portfolios`, `create_portfolios`, `edit_portfolios`, `delete_portfolios` — управление портфелями
- `view_projects`, `create_projects`, `edit_projects`, `delete_projects` — управление проектами
- `view_tasks`, `create_tasks`, `edit_tasks`, `delete_tasks` — управление задачами
- `view_documents`, `create_documents`, `edit_documents`, `delete_documents` — управление документами
- `view_artifacts`, `create_artifacts`, `edit_artifacts`, `delete_artifacts` — управление артефактами
- `view_knowledge_base`, `create_knowledge_base`, `edit_knowledge_base`, `delete_knowledge_base` — управление БЗ проекта
- `view_global_kb`, `create_global_kb`, `edit_global_kb`, `delete_global_kb` — управление глобальной БЗ
- `manage_users` — управление пользователями
- `view_all_projects` — просмотр всех проектов (не только своих)
- `cross_office_links` — создание межофисных связей

## 💾 Хранение данных

Все данные хранятся в localStorage браузера:
- `auth_state` — состояние аутентификации
- `platform_users` — пользователи
- `project-offices` — проектные офисы
- `project-office-data` — проекты
- `global-knowledge-base` — глобальная база знаний

## 🎯 Использование

1. **Вход в систему**: Используйте один из демо-пользователей или создайте своего
2. **Выбор офиса**: В разделах "Портфели" и "Проекты" выберите активный офис
3. **Управление портфелями**: Создавайте портфели и добавляйте в них проекты
4. **Работа с проектами**: Откройте проект для управления задачами, документами, артефактами
5. **Межофисные связи**: Создавайте связи между проектами разных офисов
6. **База знаний**: Используйте глобальную БЗ для обмена знаниями между проектами
